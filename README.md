# BBC2-Student-Marks-Management-System
BBC2 OOP Java Programming Group Assignment
##Description
this project is a java -based application developed for the OOP java programming assignment . it demonstrates key java programming concepts, specifically conditional statements and various loop structures, applied to solve a real work task.

### Java concepts implemeted
as required by the assignment, this application incorporates:
ternary operators- used for quick evaluation and conditional decion making
for loops- used for iterating through fixed sets of student records or marks.
while loops- used for repeating processes based on dynamic conditions.
do-while loops- used for driving menu navigation and ensuring user interaction executes at least once.
